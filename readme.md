# 🎮 GameSuite

GameSuite is a 2-in-1 JavaFX game application that includes:
- Tic Tac Toe (Single Player + Two Player modes)
- Memory Match Game with neon theme

---

## ✨ Features

### 🎯 Tic Tac Toe
- Single Player mode (Player vs Computer)
- AI uses heuristic-based logic (computer plays optimally and often wins)
- Two Player mode (Player vs Player)

### 🧠 Memory Match Game
- Card flipping memory game
- 1-minute timer challenge
- Match identical cards to score
- Win/Loss conditions
- Sound effects for actions
- Neon-themed UI

---

## 🛠 Technologies Used
- Java
- JavaFX
- Data Structures (MyStack, MyArray)
- OOP Concepts
